# 自动化脚本

这里预留自动化工具目录，目前仅包含 .gitkeep，没有可运行脚本。

| 子目录 | 规划用途 |
| --- | --- |
| jianying_draft | 剪映草稿自动生成 |
| davinci_api | 达芬奇 API 自动化 |
| ffmpeg_batch | FFmpeg 转码、裁切和批处理 |
| publish_helper | 发布素材整理、文案及清单辅助 |

添加脚本时同时提供依赖、安装方式、参数、输入输出示例和失败处理说明。默认保留源文件，先用少量素材验证，输出写入独立目录。密钥通过本地环境配置提供，不写入仓库。发布辅助工具的具体功能需后续实现。
