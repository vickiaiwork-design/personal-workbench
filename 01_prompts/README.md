# AI Prompt 库

这里保存可重复使用的 AI Prompt，按用途分类。打开对应文件，复制提示词并替换【占位符】，提交给 AI 后人工核对事实、表达和平台适配情况。

| 文件 | 用途 |
| --- | --- |
| nail_swatch_copy.md | 生成美甲试色文案 |
| tiktok_title.md | 生成 TikTok 标题 |
| xiaohongshu_note.md | 生成小红书笔记 |
| ai_channel_script.md | 生成 AI 号口播脚本 |
| crossborder_product.md | 梳理跨境选品分析 |

有效版本可直接在模板中迭代；不要将未经核实的产品信息写成事实。
