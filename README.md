# 个人工作台

这是一个面向美甲内容创作者、视频制作人员和跨境电商运营者的个人工作台，用于集中管理 AI 提示词、工作流程、内容排期、素材索引、自动化工具和运营数据。

## 目录导航

| 目录 | 用途 | 使用入口 |
| --- | --- | --- |
| 01_prompts | AI Prompt 库 | 复制模板并替换占位符 |
| 02_sops | 拍摄、剪辑和发布流程 | 按步骤执行并勾选清单 |
| 03_content-calendar | 内容日历 | 在 calendar.csv 中安排内容 |
| 04_assets | 素材索引 | 记录本地或网盘素材位置 |
| 05_automation | 自动化脚本 | 按工具类型存放未来脚本 |
| 06_data | 账号、内容和选品数据 | 在对应 CSV 中记录真实数据 |
| 07_crossborder | 跨境电商运营记录 | 管理联盟链接、样品和竞品 |
| 08_deploy | MacBook 部署说明 | 从部署指南开始 |

## 怎么用

1. 从 Prompt 库选一个模板，将【占位符】替换为实际需求，生成初稿并人工核对。
2. 在内容日历中安排平台、账号、主题和制作进度。
3. 按 SOP 拍摄、剪辑和发布，并在素材索引中记录素材位置。
4. 发布后把单条内容和账号数据填入数据模板，按统一统计窗口复盘。
5. 需要自动化时在对应目录新增脚本；切换到 MacBook 时参考部署文档。

## 维护约定

- 所有 CSV 初始只有表头，使用 UTF-8 编码；日期建议使用 YYYY-MM-DD。
- CSV 单元格若含逗号、双引号或换行，使用标准 CSV 引号规则，推荐用表格软件编辑。
- 素材原文件放在本地素材盘或网盘，仓库只保存文字索引；提交前检查暂存文件。
- 不提交密码、API 密钥、登录 Cookie 或其他敏感信息。
- 空目录通过 .gitkeep 保留；添加实际内容后可删除对应 .gitkeep。
- 自动化目录为预留空间，安装脚本目前仅为注释空壳，不会安装软件。
