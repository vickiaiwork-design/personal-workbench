# 素材索引

这里只存文字索引，照片、视频、音频和工程原文件保存在本地素材盘或网盘，不进入 Git。

| 子目录 | 索引内容 |
| --- | --- |
| nails_swatches | 甲油胶试色素材 |
| press_on_nails | 穿戴甲素材 |
| lifestyle | 生活号素材 |
| ai_demo | AI 号录屏素材 |

子目录初始使用 .gitkeep 保留。需要登记素材时，新建 Markdown 或 CSV 索引，记录素材编号、拍摄日期、主题、产品色号、路径或网盘链接、授权情况、关联内容编号和备注。不要在链接中保存访问令牌或密码。

建议按“日期_主题”命名索引；移动原素材后及时更新路径，提交前检查没有混入素材原文件。
