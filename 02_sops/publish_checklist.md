# 发布前检查清单

## 内容与素材

- [ ] 主题、产品名称和色号准确，演示与文案一致。
- [ ] 图片、音乐、字体等素材具备所需使用授权。
- [ ] 个人信息、后台信息及密钥已遮挡。
- [ ] 商业合作或联盟关系已按实际情况说明。

## 画面与声音

- [ ] 画幅、分辨率和时长适配目标发布位置。
- [ ] 无黑帧、错剪、缺失素材或意外水印。
- [ ] 字幕无错字，位置不遮挡重点，音画同步。
- [ ] 人声清晰，音乐音量适中，完整回放无异常。

## 发布设置

- [ ] 平台、账号、标题、封面、话题和链接正确。
- [ ] 预览效果正常，发布时间与内容日历一致。
- [ ] 发布后记录内容链接、发布时间并更新发布状态。
- [ ] 按预设统计窗口回填内容表现数据。
