# 拍摄 SOP

## 拍摄前

- [ ] 明确平台、账号、主题、画幅和目标时长。
- [ ] 确认脚本、镜头清单、产品色号和道具。
- [ ] 检查设备电量、存储空间、镜头和收音。
- [ ] 固定灯光、白平衡和曝光，试拍并检查颜色还原。

## 拍摄中

- [ ] 按镜头清单拍摄全景、细节、操作和结果。
- [ ] 试色记录光源、底色和涂刷层数。
- [ ] 关键镜头补拍备选版本，保留剪辑余量。
- [ ] 现场回放确认对焦、声音和主体完整。

## 拍摄后

- [ ] 将素材复制到素材盘并备份，确认可正常读取后再处理存储卡。
- [ ] 按“日期_账号_主题_镜头序号”命名或归档。
- [ ] 在 04_assets 对应分类中记录素材路径、内容与授权信息。
- [ ] 更新内容日历中的素材状态。
