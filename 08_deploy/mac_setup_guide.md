# MacBook 从零部署指南

本指南用于初始准备；具体软件安装命令和版本待实际部署时核实补充。

## 1. 准备文件

- 备份现有工作台和素材，确认备份能够打开。
- 选择 Mac 上的工作台目录，并准备素材盘或网盘。
- 确认设备芯片类型、系统版本、磁盘空间和所需软件兼容性。

## 2. 准备工具

根据实际需要，从官方渠道准备 Git、代码编辑器、Python、Node.js、FFmpeg、剪映和 DaVinci Resolve。若后续使用包管理器，先核实其官方安装方式。

install_software.sh 当前只有注释，不会安装上述软件，也不会改变系统配置。

## 3. 迁移工作台

已有远程 Git 仓库时，将其克隆到选定目录；尚未建立远程仓库时，直接复制工作台文件夹。打开 README.md，检查各目录和 CSV 表头是否完整。

## 4. 连接素材

将素材放到 Mac 本地目录、外接盘或网盘。Windows 盘符路径不能直接用于 Mac，需要更新 04_assets 中的索引，并逐项验证素材可访问。

## 5. 配置与验证

- 根据未来脚本的说明安装其依赖并单独配置环境。
- 凭据保留在本地私密配置中，不提交到仓库。
- 用表格软件按 UTF-8 导入 CSV，确认中文列名正常。
- 用一小段测试素材检查读取、字幕字体、导出和播放效果。
- 记录实际安装版本及遇到的问题，再开始批量工作。
