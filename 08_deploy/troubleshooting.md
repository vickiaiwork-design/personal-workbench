# 常见问题排查

| 问题 | 检查与处理 |
| --- | --- |
| 安装脚本运行后没有变化 | 当前是注释空壳，属于预期行为；按部署指南准备所需工具 |
| 找不到命令 | 确认软件已安装，重新打开终端并检查命令搜索路径 |
| CSV 中文乱码 | 用表格软件的导入功能选择 UTF-8 编码和逗号分隔 |
| CSV 账号编号或日期被自动转换 | 导入时将编号列设置为文本，并明确日期列格式 |
| 素材路径失效 | 确认外接盘已挂载、网盘可访问，并将 Windows 路径更新为实际 Mac 路径 |
| 字幕字体缺失 | 安装有使用授权的字体，重启剪辑软件并重新检查字幕 |
| 自动化无法执行 | 当前目录尚未提供脚本；新增脚本后按其依赖和参数说明排查 |
| 文件权限不足 | 检查目标目录访问权限和软件需要的文件访问授权，不盲目提升权限 |
| 导出异常 | 先检查磁盘空间、输入素材和输出参数，再用短片段复现并保留日志 |

记录问题时写明系统版本、软件版本、操作步骤、错误文本及处理结果；分享日志前删除敏感信息。
