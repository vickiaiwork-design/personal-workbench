# 数据追踪

这里保存运营数据 CSV 模板，所有文件初始只有表头，不包含示例或虚构数据。

- account_tracking.csv：支持 5 个账号持续追踪，使用稳定账号编号区分账号；每个统计日期、平台、账号一行，无需预填 5 行。
- content_performance.csv：单条内容的表现记录；同一内容可按不同统计时间和窗口追加记录。
- crossborder_products.csv：候选产品、成本、样品和测试进度记录。

统一使用 YYYY-MM-DD 日期，时间可用 YYYY-MM-DD HH:mm；明确统计窗口，例如“发布后24小时”。比例列按表头使用百分数，金额注明币种。缺失数据留空，真实为零才填 0。账号新增粉丝可按同一统计窗口的期末粉丝数减期初粉丝数计算；指标口径保持一致，避免直接比较不同平台口径。
